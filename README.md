# My Tbilisi Website

This is my first website! I made it about Tbilisi, the capital of Georgia.

## About

The page talks about the city, some places you can visit (like Narikala Fortress and the sulfur baths), Georgian food like khachapuri and khinkali, and why I would like to go back there.

## What I used

- HTML
- CSS

## How to open it

Just download the files and open `index.html` in your browser.

## Images

The pictures are from Unsplash.

## What I learned

- How to make headings, paragraphs and lists in HTML
- How to add images
- How to connect a CSS file to HTML
